# Frosty project visuals

These assets document the Studio 1.2 interface and its shared brand colors.

| Asset | Purpose and provenance |
| --- | --- |
| `frosty-studio-hero.svg` | Original vector project banner: Qwen Image leads, with VL and MCP alongside |
| `frosty-architecture.svg` | Original diagram of browser/agent → Studio → separate render engines |
| `frosty-image-workspace.jpg` | Native Chrome capture of the current Image UI with an empty fixture library |
| `frosty-video-workspace.jpg` | Native Chrome capture of the current VL Create view with a labeled fixture backend |
| `frosty-scene-lab.jpg` | Native Chrome capture of Scene Lab and its built-in example directions |
| `frosty-vl-hero.svg`, `frosty-vl-hero.png` | Legacy visual assets retained for existing links; superseded by the current banner/screenshots |

Screenshot date: September 21, 2026. Screenshots use the shipped HTML, CSS and JS,
including `ui/studio_theme.css`, in an isolated local preview. Readiness is supplied
by fixture responses. No model is loaded, no generated artwork is shown, and these
images are not evidence of output quality, GPU capacity or a production deployment.
Only the preview window was captured; no personal media or account tabs are included.

Brand palette: charcoal `#0c1014`, panel `#11171d`, border `#26313a`, text `#e7eef3`,
muted `#8b9ba8`, ice cyan `#9de6ed`, action mint `#b9f3c6`. Source of truth:
[ui/studio_theme.css](../ui/studio_theme.css). SVGs include accessible titles and
plain-text labels; README images include descriptive alt text.
